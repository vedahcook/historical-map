# Conflict review mockup

Three screens for reviewing conflicts between border sources:

- **Queue.dc.html:** conflicts grouped by what it takes to settle them.
- **Main.dc.html:** one conflict (Schleswig 1864–66). It shows a map, what each source says month by month, a suggested answer, the evidence, and the decision options.
- **Rules.dc.html:** definitional questions decided once, and how much each source counts.

These files were made in Claude's design canvas and need its viewer to render. `canvas.json` lays out the screens.

The map on the conflict screen is a rough sketch, not real borders.
